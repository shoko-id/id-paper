# 🧭 ID論文トレンド × コーチング壁打ち

`Streamlit` `Python` `Gemini API`

> 🚀 **公開URL**: [https://id-paper.streamlit.app/](https://id-paper.streamlit.app/)

最新のインストラクショナルデザイン（ID）や医療教育関連の論文を取得し、Gemini APIでトレンドを整理したうえで、**自分の教育実践に引き寄せてコーチング壁打ちができる** Streamlitアプリです。

## ✨ このアプリでできること

- **🔍 最新論文のピックアップ**
  キーワードと期間（直近6ヶ月 / 直近1年）を指定し、抄録のある学術論文だけを関連度順で5件取得します。
- **🌏 トレンド整理＆日本語概要**
  取得した論文の傾向から注目トピックを3つ抽出し、各論文のタイトルと要点を日本語で簡潔にまとめます。
- **💬 助言しないコーチング壁打ち**
  気になる論文を選んでボタンを押すと、IDの知見を背景に持つAIコーチが、答えを教えるのではなく「問いかけ」を通じて実践の言語化に伴走します。

## 📚 検索データベースの使い分け

| データベース | 特徴・向いているテーマ | アプリでの扱い |
| :--- | :--- | :--- |
| **PubMed** | 医学・医療教育・臨床指導の論文に特化（ノイズが少なめ） | サイドバーで切替可 |
| **OpenAlex** | 教育工学・企業研修・大学教育などID全般を広く網羅 | サイドバーで切替可 |
| **Google Scholar** | 幅広い文献を網羅的に確認したいとき | サイドバーのリンクから直接検索 |

## 🛠 使い方

1. 左サイドバーで **検索データベース**（PubMed / OpenAlex）と **対象期間** を選びます。
2. 英語でキーワードを入力し、**「論文を取得してまとめる」** をクリックします。
   - キーワード例：`medical education` / `instructional design` / `ARCS model` / `self-regulated learning`
3. 一覧から気になる論文を開き、**「この論文で壁打ちする」** をクリックします。
4. 右側のチャット欄で、AIコーチからの問いかけに答えながら思考を整理します。
