最新のインストラクショナルデザイン（ID）や教育関連論文を取得し、Gemini APIでトレンドを整理したうえで、自分の教育実践に引き寄せてコーチング壁打ちができるStreamlitアプリです。

主な機能

最新論文の取得と絞り込み：キーワードと対象期間（直近6ヶ月 / 直近1年）を指定し、タイトル・抄録に一致する論文を関連度順で5件取得します。

AIによるトレンド整理と日本語要約：取得した論文の傾向から注目トピックを3つ抽出し、各論文を日本語で簡潔に要約します。

コーチング壁打ちチャット：気になる論文を選んでボタンを押すと、鈴木克明先生や熊本大学教授システム学専攻（GSIS）のID知見を背景に持つAIコーチが、助言ではなく「問いかけ」を通じて実践の言語化に伴走します。
